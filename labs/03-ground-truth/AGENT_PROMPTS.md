# Prompts to adapt

```text
A test is labelled flaky if, across N reruns on identical code, it both passed
and failed. Do not tell me this is a reasonable approach. Tell me exactly which
inferences this procedure licenses and which it does not, and what happens to
the labels as N changes.
```

```text
I claim the negative class in this dataset is contaminated and the positive class
is clean. Argue against me as strongly as you can.
```

```text
Estimate what it would cost to rerun a 3,000-test Java suite 100 times on cloud
CI. Show the arithmetic and state every assumption as a separate line I can
challenge.
```
