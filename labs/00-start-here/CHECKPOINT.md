# Checkpoint

Hint: write down what happens next in each of the three cases, and notice that the
CI report is identical in all three.

If you can answer these, you are done with the phase:

1. Why does the same red build justify three different responses?
2. Who pays when the wrong response is chosen — and is it the same person each time?
3. What is the difference between what the system says and what the team does?
4. Why is "the test is flaky" a prediction rather than a decision?
5. What information does the CI system already have, and what is it not supplying?
