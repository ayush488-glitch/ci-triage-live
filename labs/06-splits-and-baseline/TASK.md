# Task

## Design the slice — before anything else

Write `design/06-splits-and-baseline.md` using the template in [design/README.md](../../design/README.md):
responsibility, reads, emits, refuses, constraint, connects to.

This phase's slice is **the experiment harness**.

How a run is specified and reproduced. What identifies a run, what a result is as an
object, and what has to be recorded for someone else to get the same number.

The hard question: **what stops a future you from selecting on the test set?** Design the
thing that makes it awkward, not the paragraph that asks you not to.

Do not write code until this file exists. You decide what the slice is responsible for,
what it may read, what it emits, and when it refuses.

---


**1. Predict, in writing, first.**

Open `experiments/06-split-comparison.md` and write, before running anything:

- what a random row-wise split measures;
- what a split that holds out whole projects measures;
- which number you expect to be higher, and by how much;
- what result would tell you your reasoning was wrong.

Do not edit this file after you see the result. Append to it.

**2. Ask the deployment question.** In `decisions/06-split-choice.md`: when this system runs
in production, is it seeing tests from projects it has trained on, or projects it has never
seen? Your split must match that answer. Write the answer *before* you look at which split
gives a nicer number.

**3. Build it.** `ci_triage/splits.py` — a grouped splitter. sklearn has this; use it, and
write only the wiring.

**4. The invariant test.** `tests/test_splits.py` must fail if any project appears on both
sides of any fold. This is a bug that is invisible in the metrics and fatal to the claim.

**5. Run both.** Same model, same features, both splits. Report mean and standard deviation
across folds. Write both to `artifacts/results/baseline.json`, along with the majority
baseline on the real data.

**6. Defend it.** Write the strongest critique of one reported number and your evidence-based
response in `.ci-lab/interviews/06.md` if you want to retain it. This artifact is optional.
