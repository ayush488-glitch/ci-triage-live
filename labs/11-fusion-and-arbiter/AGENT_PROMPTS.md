# Prompts to adapt

```text
I have three observer probability distributions per case. Propose five distinct
strategies for producing one verdict from them. For each, state the assumption it
makes about the observers that must be true for it to be valid.
```

```text
Implement Jensen-Shannon divergence between two probability distributions and
explain, in one paragraph, why I would use it instead of comparing argmax labels.
```

```text
Print the fully rendered prompt my arbiter received for case N. Do not summarise
it, do not describe it. Print the exact string.
```

```text
Write a test that fails if the fusion layer reports unanimous agreement while the
underlying observers are actually the same object or the same value copied.
```

```text
My LLM fusion scored 43.2% accuracy with ECE 0.458. Majority baseline is 56.8%.
Give me three hypotheses for what went wrong, ranked, with the check for each.
```
