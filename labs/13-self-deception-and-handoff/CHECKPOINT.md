# Checkpoint

Hint on the register: go back through your `experiments/` files and find every place a
number surprised you. Each one is a way the system could have lied and did not, this time.

1. Name two ways this system could report a good number while being useless.
2. What does a collapsed calibrator look like from the outside, and what distinguishes it
   from a model with no signal?
3. Which of your findings would not survive being run on a different set of projects?
4. Which doubt sent you to the literature, and what did the answer change?
5. What is the largest thing you still do not know, and what would it cost to find out?
