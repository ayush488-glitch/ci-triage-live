# Troubleshooting

**The failure register turns into a post-mortem** — you are writing what happened. Start
again from "how could this be wrong in a way I have not seen yet".

**Your literature search finds nothing relevant** — that is a finding. Record the query and
the result. It also usually means the doubt was too general; make it specific enough that a
paper could contradict it.

**A citation looks perfect but you cannot find the paper** — check it exists before it goes
in the document. Agents produce plausible references. Verify every one.

**Your known-unknowns column is short** — reread `experiments/`. Every hypothesis that came
out inconclusive is a known-unknown you have already earned.

**The invariant tests pass trivially** — break each one deliberately and confirm it fails.
A test that has never failed has never been tested.
