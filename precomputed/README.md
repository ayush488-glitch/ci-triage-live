# Precomputed results

Phase 11 fine-tunes a small language model, which needs a GPU. If you do not have one, the
runs are here.

Using these is fine. What is not fine is writing your hypothesis after reading them. Write
`experiments/11-finetune-vs-tfidf.md` first — the prediction, and the result that would
make you abandon the idea — then open this directory.

The memory-ledger arithmetic in phase 11 you do by hand regardless. That part costs nothing
and is most of the lesson.
